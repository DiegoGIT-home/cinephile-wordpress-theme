# Icone per i Box / Pilastri ("Chi Siamo")

Questa cartella contiene le icone vettoriali predefinite per i 3 box dei valori / pilastri della pagina "Chi Siamo".

## Formato e Dimensioni Consigliate per Icone Personalizzate

Se desideri caricare icone personalizzate dal pannello Customizer (Punto 6: Pagina Chi Siamo):

- **Formato consigliato:**  
  - **SVG:** Formato ideale perché vettoriale, ultraleggero (< 1 KB) e infinitamente nitido su qualsiasi display Retina / 4K.
  - **PNG o WebP:** Con sfondo trasparente (canale Alpha).
- **Dimensioni consigliate:**  
  - Risoluzione ideale del file: **64×64 pixel** (o 128×128 pixel per schermi ad altissima densità).
  - Dimensione di visualizzazione a video: **28×28 pixel** (all'interno del cerchio da 58×58 pixel).
  - Proporzioni: **1:1 (quadrata)**.
  - Peso file consigliato: inferiore a **20 KB** per mantenere il caricamento istantaneo della pagina.
