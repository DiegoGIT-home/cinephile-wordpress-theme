# Cinephile Child Theme / Tema Figlio Ufficiale

[Italiano](#italiano) | [English](#english)

---

## Italiano

Questo è il **Tema Child ufficiale** per *Cinephile - Editorial Cinema Magazine*.

### Perché usarlo?
- **Aggiornamenti Sicuri:** Quando il tema genitore (*Cinephile*) viene aggiornato, tutte le tue modifiche a questo tema child rimangono intatte al 100%.
- **CSS Personalizzato:** Scrivi il tuo stile in `style.css` per sovrascrivere o aggiungere nuove regole.
- **Funzioni PHP Custom:** Aggiungi nuovi hook, shortcode o filtri in `functions.php`.
- **Override dei Template:** Copia qualsiasi file di template dal tema genitore (es. `single.php`, `footer.php`) dentro questa cartella per modificarlo in autonomia.

### Come Installarlo:
1. Copia o sposta questa cartella `cinephile-child` all'interno della cartella dei temi di WordPress:  
   `wp-content/themes/cinephile-child/`
   *(Accanto alla cartella del tema genitore `cinemaecritica-theme`)*
2. Accedi alla bacheca di WordPress: **Aspetto → Temi**.
3. Clicca su **Attiva** sul riquadro **Cinephile Child**.

> **Nota:** Se hai rinominato la cartella del tema genitore (es. da `cinemaecritica-theme` a `cinephile`), apri il file `style.css` del child e aggiorna la riga `Template: nome-cartella-genitore`.

## English

This is the **official Child Theme** for *Cinephile - Editorial Cinema Magazine*.

### Why use it?
- **Safe Updates:** When the parent theme (*Cinephile*) receives updates, all your custom code in this child theme remains 100% untouched.
- **Custom CSS:** Add or override styling inside `style.css`.
- **Custom PHP Functions:** Add custom filters, actions, or shortcodes in `functions.php`.
- **Template Overrides:** Copy any template file from the parent theme (e.g. `single.php`, `footer.php`) into this folder to customize layout safely.

### How to Install:
1. Copy or move this `cinephile-child` folder directly into your WordPress themes directory:  
   `wp-content/themes/cinephile-child/`
   *(Alongside your parent theme folder `cinemaecritica-theme`)*
2. In your WordPress Dashboard, navigate to: **Appearance → Themes**.
3. Click **Activate** on **Cinephile Child**.

> **Note:** If you renamed the parent theme folder (e.g., from `cinemaecritica-theme` to `cinephile`), ensure the `Template: parent-folder-name` line in `style.css` matches that folder name exactly.
